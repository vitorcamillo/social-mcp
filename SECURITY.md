# Security policy

Do not publish credentials, cookies, browser profiles, screenshots, journal files, batch files, or account identifiers in issues or pull requests.

For a suspected vulnerability in the code, open a private report to the repository owner before public disclosure. Include the affected file, version, reproduction steps using synthetic data, and impact. Do not include live secrets or personal data.

The server is intended for a trusted local host. The stdio transport and CLI approval are not an authentication boundary. Protect the operating-system account and the `SOCIAL_MCP_HOME` directory, and use a separate browser profile for each account.
