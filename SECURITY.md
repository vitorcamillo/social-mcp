# Política de segurança

Não publique credenciais, cookies, perfis de navegador, screenshots, arquivos de journal, arquivos de lote nem identificadores de contas em issues ou pull requests.

Se suspeitar de uma vulnerabilidade no código, abra um relato privado para o proprietário do repositório antes de divulgá-la publicamente. Inclua o arquivo afetado, a versão, passos de reprodução usando dados sintéticos e o impacto. Não inclua segredos ativos nem dados pessoais.

O servidor foi projetado para um host local confiável. O transporte stdio e a aprovação pelo CLI não são uma fronteira de autenticação. Proteja a conta do sistema operacional e o diretório `SOCIAL_MCP_HOME`, e use um perfil de navegador separado para cada conta.
